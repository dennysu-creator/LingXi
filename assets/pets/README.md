# Spirit Pet Assets / 靈寵圖片資源

## 核心概念

本專案共 **24 隻靈寵**，以「**二十四節氣**」為基礎劃分。
使用者輸入出生年月日時辰後，系統依其出生日期所在的節氣，分配對應靈寵。

每隻靈寵同時融合：
- **中國命理**：八字月柱、五行屬性、紫微主星、奇門方位
- **西方占星**：對應星座、守護星、元素屬性
- **獨特個性**：每隻靈寵都有獨特的外觀、語氣和指引風格

## 每隻靈寵需要的圖片資源

| 檔案名稱 | 規格 | 用途 |
|----------|------|------|
| `avatar.png` | 512×512 px | 靈寵頭像（對話框、列表） |
| `full.png` | 1024×1024 px | 靈寵全身圖（靈寵主頁） |
| `evo-1.png` | 1024×1024 px | 進化階段 1（初始型態） |
| `evo-2.png` | 1024×1024 px | 進化階段 2（覺醒型態） |
| `evo-3.png` | 1024×1024 px | 進化階段 3（終極型態） |
| `icon.png` | 128×128 px | 小圖示（選單、通知） |

## 圖片風格規範

- **格式**：PNG，透明背景
- **風格**：東方神秘感 × Q 版可愛，帶靈氣光暈
- **背景**：透明（APP 深色背景 #08080f）
- **質感**：半透明靈體、金色粒子閃爍
