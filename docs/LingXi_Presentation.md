# App 總覽

## 靈犀是什麼？

- 一款結合 **AI 智能** 與 **東方命理** 的生活顧問 App
- 用戶擁有一隻根據出生節氣配對的 **靈寵**
- 靈寵以第一人稱口吻，傳達所有命理分析結果
- 三大核心功能：**面相分析**、**風水羅盤**、**易經占卜**

## 目標用戶

- 對命理玄學有興趣的年輕族群（20-40 歲）
- 需要日常運勢指引與生活建議的用戶
- 喜歡寵物養成、收集元素的休閒玩家
- 覆蓋 6 種語言的國際用戶群

## 核心價值

- **個人化**：根據八字 + 紫微 + 奇門 + 占星的綜合分析
- **對話式**：所有結果以靈寵聊天氣泡呈現
- **養成感**：靈寵會升級、進化、解鎖新能力

# 主介面 — 靈寵中心

## 對話式 UI 設計

以聊天介面為核心，所有命理結果以靈寵口吻呈現。

### 畫面四層結構

   - 自動日期分隔線

- 進入主畫面時，自動計算當日當時段運勢
- 結合四大體系（八字 35% + 紫微 30% + 奇門 25% + 占星 10%）
- 以靈寵口吻呈現五維分數 + 幸運資訊

# Feature 1 — 靈眼（面相分析）

## 核心流程

```
拍照 → 預覽確認 → Claude Vision 分析 → 靈寵口吻結果
```

## 技術實作

- 使用 `expo-camera` CameraView 前置鏡頭
- 照片以 base64 格式（quality: 0.7）傳送
- 後端呼叫 Claude Vision API (`/ai/face-reading`)
- Web 平台自動降級

## 分析結果

- **運勢等級**：大字書法體顯示
- **五官評分**：天庭 / 眉 / 眼 / 鼻 / 口（各 0-100 分）
- **AI 解讀**：靈寵口吻的專業面相分析
- **幸運物品**：emoji + 名稱 + 原因
- **幸運方位 + 數字**

## 進度體驗

- 模擬進度條（掃描 → 定位 → 分析 → 生成）
- 靈寵旁白陪伴（「正在觀察你的面相...」）
- 結果自動轉為聊天氣泡保存

# Feature 2 — 靈心（風水分析）

## 核心流程

```
GPS 定位 → 磁力計羅盤 → 奇門遁甲排盤 → AI 分析 → 結果
```

## 即時羅盤

- `expo-location` 取得 GPS 座標 + 反向地理編碼（地名）
- `expo-sensors` Magnetometer 即時方位角（200ms 更新）
- 8 方位標示：吉方金色、凶方紅色
- 指針即時跟隨磁力計旋轉

## 奇門遁甲排盤

- 根據當前時辰自動生成九宮時盤
- 八門分吉凶（開/休/生/景 = 吉，死/傷/驚/杜 = 凶）
- 方位吉凶即時映射到羅盤 UI

## AI 風水分析

- 結合 GPS 座標 + 朝向 + 八字 + 奇門資料
- 後端呼叫 Claude API (`/ai/feng-shui`)
- 回傳：場所分析 + 風水建議 + 座位建議

## 聊天氣泡

- 3x3 方位宮格圖
- 幸運方位列表
- 靈寵口吻分析文字

# Feature 3 — 靈魂（易經占卜）

## 核心流程

```
選擇類別 → 輸入問題（選填）→ 搖卦動畫 → 卦象結果
```

## 問事五大類

| 類別 | Emoji | 涵蓋 |
|------|-------|------|
| 事業 | 💼 | 工作、升遷、創業 |
| 感情 | ❤️ | 桃花、婚姻、人際 |
| 家庭 | 🏠 | 家運、搬遷、親子 |
| 健康 | 🏥 | 身體、養生、就醫 |
| 學業 | 📚 | 考試、進修、證照 |

## 卦象系統

- **64 卦完整內建**：每卦含 Unicode 符號、卦辭、詩意句
- **變卦機制**：隨機變爻 → 生成變卦
- **五類解讀**：每卦對每類問事有專屬 verdict + guidance + timing

## 互動體驗

- 搖卦時震動回饋 (`Vibration.vibrate`)
- 1.5 秒動畫（八卦符號流轉）
- 靈寵旁白：「正在為主人通靈...」

## 結果呈現

- 大字卦象符號 + 卦名
- 卦辭引用 + 詩意句（斜體）
- 問事解讀卡片（verdict 色彩編碼）
- 上下卦 + 五行 + 運勢等級
- 變卦區塊（若有變爻）
- 靈寵口吻解讀

# 六大計算引擎

## 東方命理系統

### 1. 八字命理引擎 (bazi-engine)
- 四柱天干地支計算
- 五行比例分析
- 日主強弱判定
- **權重：35%**

### 2. 紫微斗數引擎 (ziwei-engine)
- 14 主星排盤
- 12 宮位對應
- 性格 / 事業 / 感情分析
- **權重：30%**

### 3. 奇門遁甲引擎 (qimen-engine)
- 九宮時盤排布
- 八門 + 九星配置
- 吉凶方位判定
- **權重：25%**

### 4. 六十四卦引擎 (hexagram-engine)
- 文王序 64 卦完整資料
- 變爻 + 變卦機制
- 五類問事專屬解讀

## 西方占星系統

### 5. 西洋占星引擎 (astrology-engine)
- 12 太陽星座判定
- 四元素 ↔ 五行對映
- 守護星、三態、性格分析
- **權重：10%**

### 6. 統一運勢引擎 (unified-fortune-engine)
- 融合四大體系
- 五維分數：財運 / 感情 / 事業 / 健康 / 學業
- 幸運方位 / 色彩 / 數字 / 五行
